# 瓦工坊 · 仿「瞄准专家」静态演示站

仿照 [ishoutu.cn/aim](https://ishoutu.cn/aim)（爱收徒 · 瞄准专家 · 无畏契约练枪工坊）制作的**纯静态**学习演示项目。
页面结构、配色、卡片数据均取自原站真实内容整理，仅供学习交流，请勿商用。

## 功能

### 工坊页面

- 顶部导航 / 左侧快速开始栏 / 英雄区推荐轮播（5 张图各一个推荐项目，自动轮播 + 焦点卡片高亮）
- 斜切式地图切换条：全部地图 + 亚海悬城 / 霓虹町 / 隐世修所 / 天枢云阙 / 莲华古城，右侧 8 张未复刻地图（锁定态竖排文字）
- 练法筛选：全部 42 / 预瞄 36 / 架枪 3 / 背闪 1 / 名场面 2（计数由数据实时统计）
- 42 张训练卡片：真实编号（NO.XXXXXX）、难度条（简单/困难）、练法图标、游玩次数、封面取景（object-position）与原站一致
- 收藏（♡ 持久化到 localStorage）、侧栏收藏计数、`/` 键聚焦搜索、灵敏度步进器、明暗主题切换

### 3D 训练场（「开始游玩」后）

点击「开始游玩」后的流程对齐原站：全屏加载页（WORKSHOP 标题 / 地图小地图卡 / 角色立绘 /
五步加载进度条）→ 点击进入训练场（全屏 + 指针锁定）→ 第一人称 3D 训练 → 结算 → 返回工坊。

- **灰盒训练场**：Three.js r147 渲染，五图各一套氛围配色（墙体/地面/掩体/雾色），
  走廊式场地（双侧墙 + 掩体箱堆 + 立柱），AABB 碰撞
- **第一人称**：鼠标视角（灵敏度与站点 `aim-sens` 存档实时联动）、WASD 移动、
  Shift 静步、Space 跳跃、分轴碰撞滑移
- **步枪射击**：射线命中（头/身分区，爆头 +150 / 击杀 +100）、连续射击与移动/空中散布扩大、
  视觉后坐、弹匣 50/备弹 ∞、R 换弹、曳光/弹孔/枪口焰/命中准星反馈
- **训练 Bot**：程序化人形靶机，弹出动画、击倒倒地、按练法节奏生成
- **四种练法**（由每个项目的 `type` 驱动）：
  - 预瞄：走廊沿线布靶（生成时做视线可达检测），清完一波 1.2s 后刷下一波
  - 架枪：锁定走位守角度，Bot 依次从掩体后闪出，超时缩回
  - 背闪：Bot 持续绕后出现（脚步声提示），转身补枪
  - 名场面：3-2-1 倒计时后按脚本 0.9s 间隔出靶，全清提前结算「训练完成」
- **难度规则**（由 `diff` 与描述文本驱动）：困难 Bot 有反应延迟后开枪（33% 命中掉血 20-30）；
  描述含「死亡自动结束」→ 被杀即 FAIL 结算，否则死亡重开整轮；「N血量」按描述设置玩家血量
- **HUD**：得分 / 倒计时（读描述里的「N秒」）/ 命中率 / 弹药 ∞|50 / 血条 / 受击红晕 /
  右上俯视小地图（墙体、靶点、玩家箭头）/ TAB 暂停菜单（含灵敏度滑条）
- **音效**：WebAudio 程序化合成（开枪/命中/受击/换弹/Bot 开枪/脚步），零音频素材
- **结算**：得分/击杀/爆头/命中率面板 + 最佳标记，成绩写入 localStorage（每项目留 20 条），
  工坊排行榜弹窗合并本机成绩（红色「我·本机」置顶）

## 运行

无需构建、无任何依赖（Three.js 已本地化在 `js/vendor/`）：

```bash
# 方式一：直接双击 index.html 即可打开（游玩功能同样可用）

# 方式二：任意静态服务器
cd aim-workshop
python -m http.server 8080
# 或
npx serve .
```

> 游玩需要浏览器支持 WebGL 与 Pointer Lock（Chrome / Edge / Firefox 桌面版均可）。
> 指针锁定不可用时自动降级为兼容模式。

## 实现说明

- **素材**：3D 场景为程序化灰盒自建（体块几何 + 纯色材质），不使用拳头公司的地图/模型资产；
  音效为 WebAudio 合成。想要更接近原站的观感，可后续接入 CC0 素材包
  （如 Quaternius / KayKit / Kenney 的低模武器与角色 GLB）。
- **架构**：`shell.js` 只管生命周期（加载页 → 训练场 → 结算），渲染由
  `playfield.js` 负责，玩法规则由 `drills.js`（挂为 `session.runtime`）驱动，
  两者通过 playfield 暴露的接口（布点/受伤/锁定走位/视线检测等）解耦。
- **调试钩子**：`AIM_GAME.step(dt)`（手动推帧）、`AIM_GAME._skipLoading()`（同步跳过加载页）、
  `session.playfield.debug() / aimAt(x,y,z)`、`session.runtime.debug()`——用于自动化测试。
- 设计基准取自原站计算样式：卡片底 `#0e1115`、正文 `#ece8e1`、主红 `#fd4556`、
  简单绿 `#3ddc97`、难度条 14×6 斜块、900 重标题、顶部导航 64px。
- 数据整理日期：2026-10-08，之后原站内容若有更新以原站为准。
