# 瓦工坊 · 仿「瞄准专家」静态演示站

仿照 [ishoutu.cn/aim](https://ishoutu.cn/aim)（爱收徒 · 瞄准专家 · 无畏契约练枪工坊）制作的**纯静态**学习演示项目。
页面结构、配色、卡片数据均取自原站真实内容整理，仅供学习交流，请勿商用。

## 功能

- 顶部导航 / 左侧快速开始栏 / 英雄区推荐轮播（5 张图各一个推荐项目，自动轮播 + 焦点卡片高亮）
- 斜切式地图切换条：全部地图 + 亚海悬城 / 霓虹町 / 隐世修所 / 天枢云阙 / 莲华古城，右侧 8 张未复刻地图（锁定态竖排文字）
- 练法筛选：全部 42 / 预瞄 36 / 架枪 3 / 背闪 1 / 名场面 2（计数由数据实时统计）
- 42 张训练卡片：真实编号（NO.XXXXXX）、难度条（简单/困难）、练法图标、游玩次数、封面取景（object-position）与原站一致
- 卡片悬浮层「开始游玩 / 榜单」，榜单为种子伪随机演示数据
- 收藏（♡ 持久化到 localStorage）、侧栏收藏计数、`/` 键聚焦搜索、灵敏度步进器、明暗主题切换

## 运行

无需构建、无任何依赖：

```bash
# 方式一：直接双击 index.html 即可打开

# 方式二：任意静态服务器
cd aim-workshop
python -m http.server 8080
# 或
npx serve .
```

## 目录结构

```
aim-workshop/
├── index.html        # 页面骨架
├── css/style.css     # 全部样式（CSS 变量主题化）
├── js/data.js        # 42 个训练项目 + 地图 + 轮播推荐数据
├── js/app.js         # 渲染与交互逻辑（原生 JS，无框架）
└── assets/           # 图片资源（抓取自原站 CDN，已本地化）
    ├── covers/       # 地图封面（卡片 + 英雄区背景，同原站）
    ├── slices/       # 地图切片（切换条）
    ├── agents/       # 角色立绘（英雄区装饰）
    └── logo.webp
```
